# County Rainfall and Planting Advisory

## Project Summary

This project analyses monthly rainfall data for Nairobi, Nakuru, Kisumu, Mombasa, and Machakos using Python and NumPy. It cleans invalid Machakos readings, calculates annual rainfall totals and monthly averages, identifies wettest months and dry months, and recommends planting windows.

## How to Run

Open `rainfall_analysis.ipynb` in Google Colab and run all cells from top to bottom. The notebook analyses the rainfall data and generates `rainfall_summary.csv`.

## Planting Advisory

* Nairobi: April–May is the recommended planting window based on combined rainfall.
* Nakuru, Kisumu, and Mombasa: April–May is the recommended planting window based on combined rainfall.
* Machakos: November–December is the recommended planting window based on combined rainfall.

Farmers should also consider soil conditions, crop requirements, and current weather forecasts before planting.
